## Executive Diagnosis: What Makes It Still Look Like Slop?

The interface was cleansed of generic floating glow orbs and browser alerts, but the visual structure is suffering from **8 deep, systemic AI tells** that make it look amateurish and incoherent:

1. **Editorial Serif on a Precision Audio Tool:** Calistoga (a warm literary editorial serif) was applied to headlines. Real studio tools (Ableton, FabFilter, iZotope RX) never use bookish serifs for phase correlation and DSP telemetry.
2. **Inverted Dark Slabs in a Light Theme:** The app is light-themed, but suddenly drops pitch-black/dark-navy boxes (`bg-[#0F172A]`) into the middle of white cards to fake a "cyber-tech" look.
3. **Candy Rainbow Slider Meter:** Phase correlation is rendered with a harsh red-yellow-green toy gradient bar and floating black dot, looking like a mobile game health bar rather than calibrated audio equipment.
4. **Russian Doll Card Nesting:** Up to 6 layers of rounded bordered boxes nested inside each other (Session card -> Audit card -> Stem card -> Metric mini-cards -> Recommendation card).
5. **Pill Everywhere Syndrome:** Almost every label, button, badge, and metric is styled as an identical rounded pill.
6. **Tripled Redundant Messages:** Clean tracks display "Bersih" + "Tidak Ditemukan Anomali DSP" + an entire green banner saying the same thing again.
7. **Broken, Awkwardly Stacked Header Buttons:** Action buttons have mismatched padding, varying heights, and text breaking into vertical 3-line stacks (`Unggah / Sesi / Baru`).
8. **Academic Requirement Code Leakage:** Exposing university course use case IDs (`UC-11`, `UC-12`, `UC-13`, `UC-14/15`) directly in user-facing buttons, headings, and callouts.

### Tier 2: Purpose-Gate (Priority: MEDIUM)

4. **[R-01 Color & Audio Instrument Realism — Toy Rainbow Correlation Bar]**
   - **Location:** [DiagnosticTrackCard.vue:127-138](file:///home/perhanjay/Documents/Koolyeah/Semester%205/IPPL%20%7C%20Implementasi%20Perancangan%20Perangkat%20Lunak/IF2514503%20-%20Software%20Implementation%20and%20Testing%20Project/frontend/src/components/DiagnosticTrackCard.vue#L127-L138)
   - **Tell:** Phase correlation bar uses `bg-gradient-to-r from-rose-500 via-amber-400 to-emerald-500` with a thick floating black circle dot.
   - **Why it is slop:** Phase correlation is a biphasic meter (-1.0 to +1.0) centered at 0. A harsh continuous rainbow gradient bar with a floating dot looks like an arcade game energy slider, not audio test instrumentation.
   - **Fix:** Replace with an authentic audio phase meter: a biphasic bar centered at 0 with a clear zero-axis indicator, calibrated markings (`-1.0`, `0.0`, `+1.0`), and subtle red tinting only when correlation dips below zero into phase cancellation.

5. **[R-14 Component Hierarchy — Extreme Card-in-Card Nesting]**
   - **Location:** [DashboardView.vue:372](file:///home/perhanjay/Documents/Koolyeah/Semester%205/IPPL%20%7C%20Implementasi%20Perancangan%20Perangkat%20Lunak/IF2514503%20-%20Software%20Implementation%20and%20Testing%20Project/frontend/src/views/DashboardView.vue#L372), [DiagnosticTrackCard.vue:58,111,141-197,273-295](file:///home/perhanjay/Documents/Koolyeah/Semester%205/IPPL%20%7C%20Implementasi%20Perancangan%20Perangkat%20Lunak/IF2514503%20-%20Software%20Implementation%20and%20Testing%20Project/frontend/src/components/DiagnosticTrackCard.vue#L58)
   - **Tell:** Five to six layers of rounded bordered boxes nested inside each other. Inside each track card, 4 separate mini-cards enclose basic metrics like True-Peak and Crest Factor.
   - **Why it is slop:** Boxing every number into its own card is the AI default when it doesn't know how to format tabular data. It clutters the screen with border noise.
   - **Fix:** Flatten the layout. Replace the 4 mini-cards with a clean horizontal telemetry bar or compact data grid with subtle divider lines instead of separate rounded boxes.

6. **[R-27 UI States & C-1 Intentionality — Tripled Redundant Status Callouts]**
   - **Location:** [DiagnosticTrackCard.vue:95-100,255-263,290-295](file:///home/perhanjay/Documents/Koolyeah/Semester%205/IPPL%20%7C%20Implementasi%20Perancangan%20Perangkat%20Lunak/IF2514503%20-%20Software%20Implementation%20and%20Testing%20Project/frontend/src/components/DiagnosticTrackCard.vue#L95)

8. **[Craftsmanship C-4 & Layout Resilience — Asymmetric, Vertically Broken Header Buttons]**
   - **Location:** [DashboardView.vue:330-355](file:///home/perhanjay/Documents/Koolyeah/Semester%205/IPPL%20%7C%20Implementasi%20Perancangan%20Perangkat%20Lunak/IF2514503%20-%20Software%20Implementation%20and%20Testing%20Project/frontend/src/views/DashboardView.vue#L330-L355)
   - **Tell:** "Unggah Sesi Baru" button breaks text into 3 vertical lines (`Unggah / Sesi / Baru`), "Klaim Token Harian" wraps into 3 lines, and "Beli Kuota" has mismatched height and padding.
   - **Why it is slop:** Uncontrolled flex wrapping inside buttons makes action bars look broken and amateurish.
