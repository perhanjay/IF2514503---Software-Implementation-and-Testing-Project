# Panel Admin Design System v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merombak seluruh antarmuka Panel Admin (`/admin/users`, `/admin/transactions`, dan `UserSupportDrawer`) ke Design System v2 (`DESIGN.md`) sekaligus menghilangkan teks penjelasan redundan ("yapping"), menghapus tampilan UUID `user.id`, membuat tabel adaptif di mobile (`320px`), dan memecah `UserSupportDrawer.vue` menjadi modul terfokus `< 200` baris per berkas.

**Architecture:** Ekstrak formatter dan pemetaan badge bersama ke modul utilitas ES murni (`frontend/src/utils/adminFormatters.js` beruji `node --test`), pecah `UserSupportDrawer.vue` menjadi shell + 5 sub-komponen ber-outline `#111111` (tanpa UUID & tanpa kartu kebijakan peran terpisah), lalu migrasikan `AdminUsersView.vue` dan `AdminTransactionsView.vue` ke kanvas `.notebook-paper` dengan masing-masing komponen direktori adaptif (tabel di desktop, kartu ringkas di mobile). Seluruh kontrak REST API backend (`/api/v1/admin/*`) dipertahankan 100%.

**Tech Stack:** Vue 3.5 (`<script setup>`), Tailwind CSS v4, Lucide Icons (`lucide-vue-next`), Pinia 4.0, Axios, Vite 8.3, Node.js `node:test`.

**Spec:** [`docs/superpowers/specs/2026-11-22-admin-ui-v2-design.md`](../specs/2026-11-22-admin-ui-v2-design.md)

## Global Constraints

- Nol kelas legasi v1 (`bg-bone`, `border-stone`, `rounded-none`, `.btn-ink-stamp`, `.btn-bone-secondary`, `.editorial-card`, `font-mono-accent`) pada seluruh berkas admin.
- Kanvas halaman memakai `.notebook-paper` + 3 fixed pastel halos (`#20afff/12`, `#ffda40/14`, `#ff82c2/10`).
- Kartu utama memakai `rounded-[18px] border-2 border-[#111111] bg-white/95 backdrop-blur-md shadow-[3px_4px_0_#111111]`; pelat dalam ber-radius `14px`.
- Seluruh tombol aksi memakai `.btn-keycap-sm` atau `.btn-keycap-mini`; dropdown memakai `RetroSelect.vue`; ikon memakai `lucide-vue-next`.
- Angka non-audio (kuota, statistik, mutasi, tanggal `id-ID`, paginasi) memakai `Plus Jakarta Sans` + `tabular-nums`.
- Hapus UUID `user.id` dari kartu identitas akun dan footer drawer; tetap tampilkan `tx.referenceId` pada baris transaksi.
- Hilangkan paragraf penjelasan redundan di header halaman, kartu KPI, dan badan drawer; penjelasan singkat dampak penangguhan/cabut sesi hanya tampil di modal konfirmasi.
- Setiap berkas komponen/view dipertahankan `< 250` baris (target sub-komponen `< 200` baris).
- Nol perubahan backend (`backend/`), skema Prisma, atau route guard (`frontend/src/router/index.js`).

## Review Focus

- `DEDUCTION` melebihi `wallet.balance` atau input nominal `<= 0` / desimal -> peringatan inline tampil, tombol submit disabled, API tidak dipanggil (Task 2, sub-komponen `AdminTokenAdjustmentForm`).
- Admin membuka akunnya sendiri (`isSelf === true`) -> tombol `Tangguhkan Akun` nonaktif disertai pesan singkat perlindungan akun (Task 2, `AdminAccountSecurityCard`).
- Baris transaksi dengan `tx.user === null` -> tidak melempar TypeError, tampilkan fallback `"Pengguna Tidak Tersedia"` tanpa tombol drawer aktif (Task 5, `AdminTransactionsDirectory`).
- Filter/pencarian menghasilkan 0 data atau endpoint mengembalikan HTTP error -> *empty state* / *error card + tombol coba lagi* tampil tanpa terjebak skeleton `aria-busy` (Task 3, Task 4, Task 5).
- Menekan `Escape` saat modal Suspend/Cabut Sesi terbuka di atas drawer -> hanya menutup modal teratas terlebih dahulu, bukan menutup drawer sekaligus (Task 3, `UserSupportDrawer`).

     - Props: `{ showSuspend: Boolean, showRevoke: Boolean, userName: String, suspendReason: String, statusLoading: Boolean, revokeLoading: Boolean }`
